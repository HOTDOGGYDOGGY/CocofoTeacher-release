# 코코포리아 선생님 (배포본)

최신 버전 **v1.0** — [zip 받기](CocofoTeacher_v1.0.zip)

코코포리아(ccfolia.com)용 통합 편의 크롬 확장프로그램.

## 설치

1. zip 압축 해제
2. `chrome://extensions` 접속 → 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택
4. 코코포리아 탭이 이미 열려 있었다면 새로고침

## 기능

- 맞춤법 검사 (엔진 4종 + 비교, 실시간 검사, 우클릭 교정, 개인 사전, 기록)
- 방 기록·썸네일 (홈 화면 최근 방문 / 저장된 방, 방 메모)
- 캐릭터 채팅 색상 · 스탠딩 저장 · 스탠딩 사이즈 조절
- 메모 · 공지 · 세션 준비 체크리스트 (방 화면 상단/하단 고정 표시)
- 채팅 알림 소리 · 특수문자 팔레트 · 텍스트 대치
- 로그 백업 (원클릭 수집 → HTML) · 로그 스튜디오 (꾸미기·편집·합치기·통계)
- 세션 관리자 (방별 저장 데이터 정리)
- 테마 4종 (다크/라이트/모노/레트로) + 포인트색 · 디자인(기본/세로)

## 단축키

- `Alt+S` : 팝업 열기

## 이번 버전

- 첫 배포 — 맞춤법 검사(엔진 4종·실시간·우클릭 교정·개인 사전)
- 방 기록·썸네일, 캐릭터 색상·스탠딩 저장, 스탠딩 사이즈 조절
- 메모·공지·세션 준비 체크리스트, 채팅 알림 소리, 특수문자, 텍스트 대치
- 로그 백업(원클릭 수집 → HTML)과 로그 스튜디오
- 테마 4종(다크·라이트·모노·레트로)과 포인트색

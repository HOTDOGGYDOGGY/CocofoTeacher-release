# 코코포리아 선생님 (배포본)

최신 버전 **v1.1** — [zip 받기](CocofoTeacher_v1.1.zip)

코코포리아(ccfolia.com)용 통합 편의 크롬 확장프로그램.

## 설치

1. zip 압축 해제
2. `chrome://extensions` 접속 → 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택
4. 코코포리아 탭이 이미 열려 있었다면 새로고침

## 업데이트

새 버전이 나오면 팝업 상단에 안내가 뜹니다. **새 버전 받기**로 zip을 받아
압축을 풀고 **기존 폴더에 덮어쓴 뒤**, `chrome://extensions`에서 새로고침(⟳)하면 됩니다.

> ⚠️ 반드시 **처음 설치했던 그 폴더에 덮어쓰세요.** 새 폴더에 풀어서 다시 로드하면
> 크롬이 다른 확장으로 인식해 저장된 데이터(방 기록·메모·색상·사전 등)가 초기화됩니다.

## 기능

- 맞춤법 검사 (엔진 4종 + 비교, 실시간 검사, 우클릭 교정, 개인 사전, 기록)
- 방 기록·썸네일 (홈 화면 최근 방문 / 저장된 방, 방 메모)
- 캐릭터 채팅 색상 · 스탠딩 저장 · 스탠딩 사이즈 조절
- 메모 · 공지 · 세션 준비 체크리스트 (방 화면 상단/하단 고정 표시)
- 채팅 알림 소리 · 특수문자 팔레트 · 텍스트 대치
- 로그 백업 (원클릭 수집 → HTML) · 로그 스튜디오 (꾸미기·편집·합치기·통계)
- 세션 관리자 (방별 저장 데이터 정리)
- 테마 4종 (다크/라이트/모노/레트로) + 포인트색 · 디자인(기본/세로)
- 새 버전 알림 (새 배포본이 나오면 팝업에서 안내)

## 단축키

- `Alt+S` : 팝업 열기

## 이번 버전

- /system 시스템 메시지 수집 + 스튜디오 시스템 메시지 디자인 5종
- 설명 표시 끄기 — 안내문을 한 번에 숨김
- 설정 초기화 — 맞춤법만 / 코코포리아만 / 둘 다
- 검사 제외 단어 — 매번 틀렸다고 나오는 단어를 한 번에 무시 (조사만 다른 말도 묶어서)
- 실시간 검사 엔진을 따로 지정 (다음·네이버·사람인·인크루트·비교)
- 새 버전 알림과 업데이트 내역 화면
- 세로 디자인 개편 — 입력칸이 넓어지고 잘리던 [검사하기] 수정
- 코코포리아 탭 순서 드래그, 고정 메모 설정을 방 안 패널로 이동
- 로그 수집 속도 2~3배 향상, 패널·스튜디오 전반 성능 개선
- 시스템 메시지 집계·미리보기 이미지·받기 링크 등 버그 수정

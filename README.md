# 코코포리아 선생님 (배포본)

최신 버전 **v1.3** — [zip 받기](CocofoTeacher_v1.3.zip)

코코포리아(ccfolia.com)용 통합 편의 크롬 확장프로그램.

## 설치

1. zip 압축 해제
2. `chrome://extensions` 접속 → 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택
4. 코코포리아 탭이 이미 열려 있었다면 새로고침

## 업데이트

새 버전이 나오면 팝업 상단에 안내가 뜹니다. **새 버전 받기**로 zip을 받아
압축을 풀고 **기존 폴더에 덮어쓴 뒤**, `chrome://extensions`에서 새로고침(⟳)하면 됩니다.

> ⚠️ 반드시 **처음 설치했던 그 폴더에 덮어쓰세요.** 새 폴더에 풀어서 다시 로드하면
> 크롬이 다른 확장으로 인식해 저장된 데이터(방 기록·메모·색상·사전 등)가 초기화됩니다.

## 기능

- 맞춤법 검사 (엔진 4종 + 비교, 실시간 검사, 우클릭 교정, 개인 사전, 기록)
- 방 기록·썸네일 (홈 화면 최근 방문 / 저장된 방, 방 메모)
- 캐릭터 채팅 색상 · 스탠딩 저장 · 스탠딩 사이즈 조절
- 메모 · 공지 · 세션 준비 체크리스트 (방 화면 상단/하단 고정 표시)
- 채팅 알림 소리 · 특수문자 팔레트 · 텍스트 대치
- 로그 스튜디오 — 코코포리아 로그 내보내기 파일(HTML·JSON·ZIP)을 꾸미기·편집·합치기·통계
- 세션 관리자 (방별 저장 데이터 정리)
- 테마 4종 (다크/라이트/모노/레트로) + 포인트색 · 디자인(기본/세로)
- 새 버전 알림 (새 배포본이 나오면 팝업에서 안내)

## 단축키

- `Alt+S` : 팝업 열기

## 개인정보 · 외부 전송

- 방 기록 · 메모 · 캐릭터 정보 · 로그 설정은 이 컴퓨터의 크롬 저장소에만 저장되고 어디로도 보내지 않습니다.
- 맞춤법 검사는 검사할 글을 고른 엔진의 사이트(다음 · 네이버 · 사람인 · 인크루트)로 보내 결과를 받아 옵니다.
  실시간 검사는 기본으로 꺼져 있고, 비밀번호 · 카드 번호 · 인증 번호 칸의 글은 보내지 않습니다.
- 새 버전 확인은 배포 저장소의 version.json 만 읽습니다. 자동 업데이트는 배포자의 서명이 맞는 zip 만 폴더에 덮어씁니다.
- 다른 확장 목록을 보는 권한은 설정의 [겹치는 확장 확인]을 눌러 허용할 때만 받습니다.

## 이번 버전

### 로그 스튜디오

- 명령어 판정 개선 — '/눈물닦기'처럼 명령어가 아닌 채팅을 명령어로 처리하던 문제 수정
- 주사위 판정 개선 — 공식 JSON 로그의 주사위 결과 누락 수정, choice·D66·표 굴림 인식, 1D6이 들어간 설명문은 대사로 처리
- 캐릭터별 인장 설정 수정 — 다른 로그의 같은 이름 캐릭터에도 적용되던 문제 수정 (로그마다 따로 저장, 같은 이름의 다른 캐릭터는 인장 그림으로 구분)
- 인장 보정 '매끈하게' 수정 — 확대하거나 화면 배율을 올리면 지나치게 흐려지던 문제
- 탭 수정 — 탭 이름을 바꾸면 다른 탭으로 갈라지던 문제, 한 탭 모양을 바꾸면 다른 탭 색이 바뀌던 문제, 탭이 비어 있는 대사가 '메인' 설정을 따르지 않던 문제
- 설정·되돌리기 수정 — 스타일 불러오기·초기화 때 캐릭터별 인장 설정이 지워지던 문제, 다른 로그를 연 뒤 Ctrl+Z가 이전 로그로 덮어쓰던 문제, 받은 설정 파일에 잘못된 값이 있으면 저장한 로그가 깨질 수 있던 문제
- 다시 열기 수정 — 저장한 로그를 다시 열 때 탭 이름·판정표가 깨지던 문제, 공식 로그 여러 개를 한 번에 열면 시간순으로 합쳐지지 않던 문제
- 기타 — 메신저 말꼬리 모서리 정리, 비표시 줄 때문에 이름·인장이 사라지던 문제, 판정 이름의 '성공' 글자로 실패 주사위가 성공 색이 되던 문제

### 캐릭터 패널

- 발화 캐릭터 단축키 추가 — Ctrl + 숫자로 칩 순서대로 전환 (기본 꺼짐. Ctrl + Shift · Shift + Alt · ` + 숫자 등으로 변경 가능)
- 패널 디자인 정리 — 스위치를 오른쪽으로 모으고 설정을 카드로 묶음, ? 설명이 윈도우 툴팁과 겹쳐 뜨던 문제 수정
- 오류 수정 — 방 이름·메모가 되돌아갈 수 있던 문제, 패널을 끈 채 들어온 방에서 켜면 일부 기능이 시작되지 않던 문제, 스탠딩 여러 장 가져오기·표정 이름 변경 관련 문제 등

### 맞춤법 검사·텍스트 대치

- 검사 서버가 응답하지 않으면 20초 뒤 중단, 설정에 [엔진 점검] 추가
- 교정 정확도 개선 — '할수 → 할 수'가 '할수록'까지 바꾸던 문제, 교정이 겹쳐 붙던 문제, 우클릭 교정이 엉뚱한 자리를 고치던 문제 수정
- 텍스트 대치 수정 — 'ㅋㅋㅋㅋ'처럼 한글로 끝나는 규칙이 동작하지 않던 문제, 저장 한도를 넘으면 저장된 것처럼 보이던 문제

### 채팅 알림

- 같은 말을 반복하면 알림이 오지 않던 문제, 소리를 꺼도 알림음이 나던 문제, 여러 창에서 중복으로 울리던 문제, 알림을 눌러도 방으로 이동하지 않던 문제 수정

### 보안

- 자동 업데이트 서명 확인 — 배포자가 서명한 zip 만 설치 폴더에 덮어씀 (배포 저장소가 바뀌어도 다른 파일이 들어오지 않게)
- 권한 줄이기 — 다른 확장 목록을 보는 권한은 설정의 [겹치는 확장 확인]을 눌러 허용할 때만 받음, 글꼴·알림음 파일은 코코포리아에서만 열림
- 맞춤법 검사 — 카드 번호·인증 번호 칸은 실시간 검사로 보내지 않음, 검사 엔진 설정에 글이 어디로 가는지 안내 추가
- 로그 스튜디오 — 손상됐거나 적힌 크기보다 크게 풀리는 zip 은 열지 않음, 로그 속 이미지는 내 컴퓨터·공유기 안쪽 주소에서 받지 않음, 예시 데이터 인장을 확장 안 그림으로 바꿈
- 기타 — 저장된 방 주소·밑줄 모양·가져온 캐릭터 색 등 저장값을 쓰기 전에 한 번 더 확인

### 기타

- 자동 업데이트가 중간에 끊기면 다시 시도할 수 없던 문제 등 오류 수정

# 코코포리아 선생님 (배포본)

최신 버전 **v1.2** — [zip 받기](CocofoTeacher_v1.2.zip)

코코포리아(ccfolia.com)용 통합 편의 크롬 확장프로그램.

## 설치

1. zip 압축 해제
2. `chrome://extensions` 접속 → 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택
4. 코코포리아 탭이 이미 열려 있었다면 새로고침

## 업데이트

새 버전이 나오면 팝업 상단에 안내가 뜹니다. **새 버전 받기**로 zip을 받아
압축을 풀고 **기존 폴더에 덮어쓴 뒤**, `chrome://extensions`에서 새로고침(⟳)하면 됩니다.

> ⚠️ 반드시 **처음 설치했던 그 폴더에 덮어쓰세요.** 새 폴더에 풀어서 다시 로드하면
> 크롬이 다른 확장으로 인식해 저장된 데이터(방 기록·메모·색상·사전 등)가 초기화됩니다.

## 기능

- 맞춤법 검사 (엔진 4종 + 비교, 실시간 검사, 우클릭 교정, 개인 사전, 기록)
- 방 기록·썸네일 (홈 화면 최근 방문 / 저장된 방, 방 메모)
- 캐릭터 채팅 색상 · 스탠딩 저장 · 스탠딩 사이즈 조절
- 메모 · 공지 · 세션 준비 체크리스트 (방 화면 상단/하단 고정 표시)
- 채팅 알림 소리 · 특수문자 팔레트 · 텍스트 대치
- 로그 스튜디오 — 코코포리아 로그 내보내기 파일(HTML·JSON·ZIP)을 꾸미기·편집·합치기·통계
- 세션 관리자 (방별 저장 데이터 정리)
- 테마 4종 (다크/라이트/모노/레트로) + 포인트색 · 디자인(기본/세로)
- 새 버전 알림 (새 배포본이 나오면 팝업에서 안내)

## 단축키

- `Alt+S` : 팝업 열기

## 이번 버전

### 로그 스튜디오 확장 및 수정

- 로그 백업 관련 기능 제거 — 이제 코코포리아 공식에서 이미지 포함 로그 백업을 지원합니다.
- 코코포리아 공식 로그 내보내기 전 형식 지원
- 로그 가져오기 관련 기능 확장 및 오류 수정
- 로그 스튜디오 캐릭터 편집 확장 — 이름·색·인장 일괄 변경, 실제로 쓰인 이름 색을 전부 집계, 삭제 및 합치기, 캐릭터별 스탠딩 확대 및 보정

### 캐릭터 패널 확장 및 수정

- 발화 캐릭터 관련 기능 확장 및 오류 수정 — 스탠딩이 없는 새 캐릭터도 표시, 접기/펼치기, 끌어서 순서 바꾸기
- 스탠딩 여러 장 한 번에 가져오기 — 코코포리아 캐릭터 편집창에 원본 화질 그대로 넣기, 파일 이름에서 캐릭터·옷·표정·번호를 인식
- 옷장 추가 — 스탠딩을 옷별로 나눠 보기, 옷장 추가·이름 변경·삭제
- 스탠딩 목록 기능 확장 — 이름순·추가순·직접순 정렬, 5·6열, 패널 크기에 맞춰 열 수 자동 조절, 크게 확대한 스탠딩 선명하게 자동 보정
- 스탠딩 우클릭 메뉴 추가 — 맵시트 기본 스탠딩 바로 바꾸기, 표정 지우기, 패널에서만 숨기기 (편집창을 다시 열어도 숨김 유지, [고치기]에서 다시 보이기)
- 캐릭터 JSON 가져오기·내보내기

### 기타

- 텍스트 대치 기능 확장 — 정규식·스니펫 규칙 (;약어 + 스페이스/Tab → 긴 문장, {날짜} {시간} {요일}), 규칙 수정, 방 전용 규칙 추가
- 채팅 알림 확장 및 오류 수정 — 세분화 (소리 알림 외 데스크톱 알림 추가, 알림 받을 탭 지정, 내 이름이 언급될 때만 알림 기능 추가)
- 통계 리포트 기능 확장 — 대성공/대실패 목록 추가, 통계 이미지 카드(PNG) 저장
- 화면 구조 진단 기능 추가 — 코코포리아 사이트 업데이트로 인해 안 되는 기능이 있으면 방 입장 시 배너로 안내, 패널 [로그] 탭에서 언제든 검사
- 자동 업데이트 — 설치 폴더를 한 번 지정해두면 새 버전 받기·덮어쓰기, 업데이트 확인이 404일 때 '저장소가 비공개거나 파일 없음'으로 구분해 안내
- 코코포리아 사이트 업데이트 대응 — 바뀐 채팅 목록 구조 지원, 새로 만든 빈 방에서 화면 구조 경고가 잘못 뜨던 문제 수정
- 기타 편의성 수정
